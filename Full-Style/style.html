CSS Fundamentals Review

CSS Basics

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style HTML elements with colors, layouts, spacing, fonts, backgrounds, and more.

Basic CSS Syntax

selector {
  property: value;
}

Viewport Meta Tag

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

Helps pages scale correctly on phones and tablets.

Default Browser Styles

Browsers automatically apply default styles like margins, padding, and font sizes.

Inline, Internal, and External CSS

Inline CSS

<p style="color:red;">Hello</p>

Written directly inside the element.

Internal CSS

<style>
p {
  color: blue;
}
</style>

Written inside the HTML file.

External CSS

<link rel="stylesheet" href="styles.css">

Best choice for large projects.

Width and Height

  • width sets width
  • min-width sets minimum width
  • max-width sets maximum width
  • height sets height
  • min-height sets minimum height
  • max-height sets maximum height
div {
  width: 300px;
  min-height: 200px;
}

CSS Combinators

Descendant Combinator

ul li {
  color: red;
}

Targets all li elements inside ul.

Child Combinator >

.container > p {
  color: blue;
}

Targets direct children only.

Next-sibling Combinator +

h2 + p {
  background: yellow;
}

Targets the first paragraph after h2.

Subsequent-sibling Combinator ~

ul ~ p {
  color: green;
}

Targets all matching siblings after ul.

Display Types

Type Description
Inline Takes only needed width
Block Takes full width
Inline-block Inline but accepts width and height 
display: inline;
display: block;
display: inline-block;

Margin and Padding

Margin

Margin creates space outside the border of an element.

Individual Margin Properties

  • margin-top → space above the element
  • margin-right → space on the right side
  • margin-bottom → space below the element
  • margin-left → space on the left side
div {
  margin-top: 20px;
  margin-right: 15px;
  margin-bottom: 30px;
  margin-left: 10px;
}

Padding

Padding creates space inside the border, between the content and the border.

Individual Padding Properties

  • padding-top → space above content
  • padding-right → space on the right side
  • padding-bottom → space below content
  • padding-left → space on the left side
div {
  padding-top: 20px;
  padding-right: 15px;
  padding-bottom: 30px;
  padding-left: 10px;
}

Shorthand Margin

margin: 20px;

Applies 20px to all sides. 

margin: 10px 20px;

Top and bottom = 10px. Right and left = 20px. 

margin: 10px 20px 30px;

Top = 10px. Right and left = 20px. Bottom = 30px. 

margin: 10px 20px 30px 40px;

Top, right, bottom, left.

Shorthand Padding

padding: 20px;
padding: 10px 20px;
padding: 10px 20px 30px;
padding: 10px 20px 30px 40px;
Order in shorthand always goes: top → right → bottom → left

CSS Specificity

Selector Specificity
Inline Style (1,0,0,0)
ID Selector (0,1,0,0)
Class Selector (0,0,1,0)
Type Selector (0,0,0,1)
Universal Selector * (0,0,0,0) 
#title {
  color: red;
}

.text {
  color: blue;
}

p {
  color: green;
}

!important

p {
  color: red !important;
}

Overrides almost all other styles.

Use carefully because it makes CSS harder to maintain.

Cascade Algorithm

Browser decides which CSS rule wins using:

  1. Relevance
  2. Origin and Importance
  3. Specificity
  4. Order of Appearance
p {
  color: blue;
}

p {
  color: green;
}

Green wins because it appears later.

CSS Inheritance

Some styles pass from parent elements to children. 

body {
  color: blue;
}

Child text elements inherit the blue color.
