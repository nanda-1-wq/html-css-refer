HTML Forms & Tables Reference

1. The <form> Element

<form>
Creates an HTML form for collecting user input. All form controls go inside this element.
action
URL where form data is sent on submission. Omit or use "" to send to current page.
method
GET — appends data to URL (bookmarkable, for search/filtering). POST — sends data in request body (for sensitive data, file uploads, changes).
enctype
Encoding type for POST: "application/x-www-form-urlencoded" (default), "multipart/form-data" (required for file uploads), "text/plain"
autocomplete
"on" (default) or "off" — controls browser autocomplete for the whole form
novalidate
Boolean: skips browser's built-in validation (useful when doing custom validation)
target
Where to show the response: "_self" (default), "_blank" (new tab)
<!-- POST form (most common for forms that change data) --> <form method="POST" action="/submit"> ...inputs... </form> <!-- GET form (for search) --> <form method="GET" action="/search"> <label for="q">Search:</label> <input type="search" id="q" name="q"> <button type="submit">Search</button> </form> <!-- Submitting goes to /search?q=your+query --> <!-- Form with file upload --> <form method="POST" action="/upload" enctype="multipart/form-data"> <input type="file" name="document"> <button type="submit">Upload</button> </form>

2. The <input> Element (Void)

The most versatile form element. Its behavior is entirely determined by the type attribute. No closing tag.

<input> — Common Attributes
type
Determines input behavior (see full list below). Default: "text".
id
Unique ID — must match label's for attribute for accessibility.
name
Key sent to server with form data (e.g., name="email" → email=value@form). Required for data to be submitted.
value
Default value, or button label for type="button/submit/reset".
placeholder
Hint text shown inside empty input (disappears when typing). Not a substitute for <label>.
required
Boolean: form cannot be submitted if this field is empty.
disabled
Boolean: input is non-interactive and greyed out. Value is NOT submitted with form.
readonly
Boolean: user cannot change the value, but it IS submitted with form. Different from disabled.
checked
Boolean: used with type="checkbox" and type="radio" — checked by default.
multiple
Boolean: for file inputs (allow multiple files) and email inputs (allow multiple emails, comma-separated).
autocomplete
Hint to browser: "on", "off", "name", "email", "username", "current-password", "new-password", "tel", "street-address", etc.
autofocus
Boolean: this input gets focus when the page loads. Use only once per page.
form
ID of the <form> this input belongs to — allows placing input outside the <form> element.

Text Validation Attributes

Text & Number Constraints
minlength
Minimum number of characters. For text, email, password, search, tel, url.
maxlength
Maximum number of characters allowed.
min
Minimum value for number, range, date, time, datetime-local, month, week inputs.
max
Maximum value for numeric/date inputs.
step
Legal intervals for number/range/date. "any" allows any value.
size
Visual width in characters (not a validation rule — just affects displayed width).
pattern
Regular expression the value must match. Add title attribute to explain the pattern.
<!-- Text with length limits --> <input type="text" name="username" minlength="3" maxlength="20" required> <!-- Number with range --> <input type="number" name="age" min="0" max="120" step="1"> <!-- Pattern validation --> <input type="text" name="zip" pattern="[0-9]{5}" title="Five-digit ZIP code" placeholder="12345" > <!-- Password with minlength --> <input type="password" name="password" minlength="8" required>

4. Labels — <label>

<label>
Associates a text description with a form input. Clicking the label focuses/activates the input. Required for accessibility — screen readers read the label when the input is focused.
for
ID of the associated input element (explicit association). Must match input's id attribute.
<!-- Explicit association: label "for" matches input "id" --> <label for="email">Email Address:</label> <input type="email" id="email" name="email"> <!-- Implicit association: input is nested inside label --> <label> Full Name: <input type="text" name="name"> </label> <!-- Checkbox with label (explicit) --> <input type="checkbox" id="subscribe" name="subscribe" value="yes"> <label for="subscribe">Subscribe to newsletter</label> <!-- Radio group --> <fieldset> <legend>Preferred contact method:</legend> <input type="radio" id="contact-email" name="contact" value="email"> <label for="contact-email">Email</label> <input type="radio" id="contact-phone" name="contact" value="phone"> <label for="contact-phone">Phone</label> </fieldset>
⚠️ Never skip labels! Using only placeholder text is not accessible — placeholders disappear when the user starts typing. Always use <label>.

5. Buttons — <button>

<button>
Creates a clickable button. More flexible than <input type="submit"> because it can contain HTML (text, icons, images). Default type inside a form is "submit" — always specify type explicitly.
type
submit — submits the form (default inside <form>). reset — resets all form fields. button — no default action; use with JavaScript.
disabled
Boolean: prevents clicking. Visually greyed out.
form
ID of the form this button belongs to (allows button outside the <form> element).
formaction
Overrides the form's action URL for this specific submit button.
formmethod
Overrides the form's method (GET/POST) for this submit button.
formnovalidate
Boolean: skips validation when this submit button is clicked (e.g., "Save as Draft").
<form method="POST" action="/submit"> <input type="email" name="email" required> <!-- Generic button (no form action) --> <button type="button" onclick="showPreview()">Preview</button> <!-- Reset form --> <button type="reset">Clear Form</button> <!-- Save as draft (skip validation, different action) --> <button type="submit" formaction="/save-draft" formnovalidate>Save Draft</button> <!-- Submit --> <button type="submit">Submit</button> <!-- Button with icon (more flexible than input type="submit") --> <button type="submit"> <span aria-hidden="true">✓</span> Submit Form </button> </form>

6. Textarea — Multi-Line Text

<textarea>
Multi-line text input. Unlike <input>, it has a closing tag and its default value goes between the tags (not in a value attribute). Usually resizable by the user.
rows
Visible number of text rows (visual height). Default: 2.
cols
Visible width in characters. Default: 20. Better controlled with CSS width.
placeholder
Hint text shown when empty
maxlength
Maximum character count
minlength
Minimum character count
required
Boolean: must have content before submission
disabled
Boolean: non-interactive, not submitted
readonly
Boolean: user can read but not edit; value IS submitted
wrap
"soft" (default: line breaks not sent to server), "hard" (line breaks are sent), "off" (no wrapping)
spellcheck
"true" or "false"
<label for="bio">Biography:</label> <textarea id="bio" name="bio" rows="5" cols="50" placeholder="Tell us about yourself..." maxlength="500" required ></textarea> <!-- With default content --> <textarea name="notes">This is the default text content.</textarea> <!-- Do NOT add space between tags (it becomes the default value) --> <!-- Bad: <textarea> </textarea> — has a space as default value --> <!-- Good: <textarea></textarea> -->

7. Select & Dropdown — <select>

<select>, <option>, <optgroup>
Creates a dropdown list of options. <option> defines each choice. <optgroup> groups related options.
name
Key submitted with form (on <select>)
id
To associate with <label> (on <select>)
multiple
Boolean (on <select>): allows selecting multiple options (Ctrl/Cmd+click)
size
Number of visible options at once (on <select>). With size > 1, renders as a listbox, not dropdown.
disabled
Boolean: disables the entire select
required
Boolean: user must select a non-empty option
value
The value submitted when this option is selected (on <option>). If omitted, the text content is used.
selected
Boolean (on <option>): this option is selected by default
disabled
Boolean (on <option>): this option cannot be selected
label
Short label for <optgroup> — the group heading text
<!-- Basic dropdown --> <label for="country">Country:</label> <select id="country" name="country" required> <option value="">-- Select a country --</option> <option value="us">United States</option> <option value="uk">United Kingdom</option> <option value="ca" selected>Canada (pre-selected)</option> <option value="au">Australia</option> </select> <!-- Grouped options with optgroup --> <label for="language">Programming Language:</label> <select id="language" name="language"> <optgroup label="Frontend"> <option value="html">HTML</option> <option value="css">CSS</option> <option value="js">JavaScript</option> </optgroup> <optgroup label="Backend"> <option value="python">Python</option> <option value="node">Node.js</option> </optgroup> </select> <!-- Multi-select listbox --> <label for="skills">Skills (Ctrl+click to select multiple):</label> <select id="skills" name="skills" multiple size="5"> <option value="html">HTML</option> <option value="css">CSS</option> <option value="js">JavaScript</option> <option value="react">React</option> <option value="python">Python</option> </select>

8. Datalist — Autocomplete Suggestions

<datalist>
Provides a list of pre-defined autocomplete suggestions for an <input>. Unlike <select>, the user can also type anything — the suggestions are optional. Link with input via list attribute.
<label for="browser">Preferred browser:</label> <input type="text" id="browser" name="browser" list="browser-options"> <datalist id="browser-options"> <option value="Chrome"> <option value="Firefox"> <option value="Safari"> <option value="Edge"> <option value="Opera"> </datalist> <!-- Works with other input types too --> <label for="quantity">Quantity:</label> <input type="number" id="quantity" name="quantity" list="qty-suggestions"> <datalist id="qty-suggestions"> <option value="1"> <option value="5"> <option value="10"> <option value="25"> <option value="100"> </datalist>

9. Fieldset & Legend

<fieldset> and <legend>
<fieldset> groups related form controls with a visible border. <legend> provides a caption/title for the group (must be the first child of fieldset). Essential for accessibility — screen readers announce the legend when entering the group.
disabled
Boolean on <fieldset>: disables all form controls inside the group at once.
form
Associates fieldset with a form by its ID
name
Name for the fieldset element (for JavaScript use)
<form method="POST" action="/register"> <fieldset> <legend>Personal Information</legend> <label for="full-name">Full Name:</label> <input type="text" id="full-name" name="name" required> <label for="email">Email:</label> <input type="email" id="email" name="email" required> </fieldset> <!-- Radio group (ALWAYS use fieldset + legend for radio groups) --> <fieldset> <legend>Preferred Contact Method</legend> <input type="radio" id="by-email" name="contact" value="email"> <label for="by-email">Email</label> <input type="radio" id="by-phone" name="contact" value="phone"> <label for="by-phone">Phone</label> </fieldset> <!-- Checkbox group --> <fieldset> <legend>Skills (check all that apply)</legend> <input type="checkbox" id="html" name="skills" value="html"> <label for="html">HTML</label> <input type="checkbox" id="css" name="skills" value="css"> <label for="css">CSS</label> <input type="checkbox" id="js" name="skills" value="js"> <label for="js">JavaScript</label> </fieldset> <!-- Disable an entire group --> <fieldset disabled> <legend>Payment (unavailable)</legend> <input type="text" name="card"> <input type="text" name="cvv"> </fieldset> <button type="submit">Register</button> </form>

12. HTML Tables

📌 Tables are for tabular data — data with rows and columns. Never use tables for page layout.

Table Structure Elements

ElementPurposeNotes
<table>Creates the tableWrapper for all table elements
<caption>Table title/descriptionFirst child of <table>. Important for accessibility.
<thead>Groups header rowsContains column header <tr> rows
<tbody>Groups body rows (the data)Main data content. Can have multiple <tbody> elements.
<tfoot>Groups footer rowsTotals, averages, summaries. Renders last even if placed before <tbody>.
<tr>Table rowUsed inside thead, tbody, or tfoot
<th>Table header cellBold and centered by default. Use for column and row headers.
<td>Table data cellRegular table cell with content
<colgroup>Groups columns for stylingContains <col> elements
<col>Single column or span of columnsVoid element. Apply styles to columns without repeating on each cell.

Cell Spanning Attributes

colspan and rowspan
colspan
Number of columns the cell spans (merges cells horizontally). Used on <td> or <th>.
rowspan
Number of rows the cell spans (merges cells vertically). Used on <td> or <th>.
<table> <tr> <td colspan="2">Spans 2 columns</td> <td>Col 3</td> </tr> <tr> <td rowspan="2">Spans 2 rows</td> <td>B</td> <td>C</td> </tr> <tr> <td>E</td> <td>F</td> </tr> </table>

Accessibility Attributes for Tables

scope, headers, id (on <th> and <td>)
scope
On <th>: "col" (header for a column), "row" (header for a row), "colgroup", "rowgroup". Helps screen readers associate headers with data cells.
id
On <th>: gives the header a unique ID so data cells can reference it with headers attribute.
headers
On <td>: space-separated list of <th> id values that label this cell. Used in complex tables.
<!-- Complete table with all best practices --> <table> <caption>Calculus Final Exam Grades</caption> <colgroup> <col style="width: 30%"> <col style="width: 30%"> <col style="width: 40%"> </colgroup> <thead> <tr> <th scope="col">Last Name</th> <th scope="col">First Name</th> <th scope="col">Grade</th> </tr> </thead> <tbody> <tr> <td>Davis</td> <td>Alex</td> <td>54</td> </tr> <tr> <td>Doe</td> <td>Samantha</td> <td>92</td> </tr> <tr> <td>Rodriguez</td> <td>Marcus</td> <td>88</td> </tr> <tr> <td>Thompson</td> <td>Jane</td> <td>77</td> </tr> <tr> <td>Williams</td> <td>Natalie</td> <td>83</td> </tr> </tbody> <tfoot> <tr> <td colspan="2">Class Average</td> <td>78.8</td> </tr> </tfoot> </table>
