HTML Basics Reference

1. What Is HTML?

HTML (HyperText Markup Language) defines the content and structure of a web page. It is not a programming language — it is a markup language that uses elements (tags) to describe different types of content.

HTML Element Syntax
Most elements have an opening tag, content, and a closing tag.
<elementName>Content goes here</elementName> <p>This is a paragraph.</p> <h1>This is a heading.</h1> <a href="page.html">This is a link.</a>
Void Elements (Self-Closing)
Some elements have no content and no closing tag. They are called void elements.
<img src="photo.jpg" alt="A photo"> <br> <hr> <input type="text"> <meta charset="UTF-8">
HTML Comments
Comments are not displayed in the browser. Used to explain code.
<!-- This is a comment. It won't show in the browser. --> <!-- Multi-line comment: Line 1 Line 2 -->

2. Document Structure

Every HTML document follows this structure:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Page Title</title> <link rel="stylesheet" href="style.css"> </head> <body> <!-- Visible page content goes here --> <h1>Hello World</h1> <p>Welcome to my page.</p> <script src="script.js"></script> </body> </html>
<!DOCTYPE html>
Tells the browser this is an HTML5 document. Must be the very first line. Not a tag — a declaration.
<html>
The root element. Wraps the entire document.
lang
Specifies the language of the page (e.g., "en", "ar", "fr"). Important for accessibility and SEO.
dir
Text direction: "ltr" (left-to-right) or "rtl" (right-to-left)
<head>
Contains metadata and document settings — not visible content. Holds <meta>, <title>, <link>, <script>, and <style>.
<body>
Contains all visible page content — text, images, links, etc.
<title>
Sets the page title shown in the browser tab, bookmarks, and search engine results. There should be exactly one per page.
<title>My Portfolio | Jane Doe</title>

3. Head Elements

<meta>
Provides metadata about the document. Void element — no closing tag.
charset
Character encoding. Always use UTF-8.
name
Meta tag type: "viewport", "description", "keywords", "author", "robots"
content
The value associated with the name or http-equiv attribute
property
Used for Open Graph (social media) tags: "og:title", "og:description", etc.
http-equiv
HTTP header simulation: "refresh", "content-type", "X-UA-Compatible"
<!-- Character encoding (always first) --> <meta charset="UTF-8"> <!-- Responsive design (always include) --> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- SEO description (shown in search results) --> <meta name="description" content="A portfolio website by Jane Doe."> <!-- Author --> <meta name="author" content="Jane Doe"> <!-- Keywords (less important today) --> <meta name="keywords" content="HTML, CSS, web development"> <!-- Tell search engines not to index this page --> <meta name="robots" content="noindex, nofollow"> <!-- Open Graph for social media previews --> <meta property="og:title" content="My Portfolio"> <meta property="og:description" content="Web developer portfolio"> <meta property="og:image" content="https://example.com/preview.jpg"> <meta property="og:url" content="https://example.com"> <!-- Twitter Card --> <meta name="twitter:card" content="summary_large_image"> <meta name="twitter:title" content="My Portfolio">
<link>
Links to external resources. Most commonly used to link CSS stylesheets. Void element.
rel
Relationship type: "stylesheet", "icon", "canonical", "preload", "manifest"
href
URL of the external resource
type
MIME type of the linked resource (e.g., "text/css")
media
Media query for conditional loading (e.g., "print")
<!-- Link a CSS stylesheet --> <link rel="stylesheet" href="style.css"> <!-- Favicon (browser tab icon) --> <link rel="icon" href="favicon.ico" type="image/x-icon"> <link rel="icon" href="favicon.png" type="image/png"> <!-- Canonical URL (for SEO, avoids duplicate content) --> <link rel="canonical" href="https://example.com/page"> <!-- Google Fonts --> <link rel="preconnect" href="https://fonts.googleapis.com"> <link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" rel="stylesheet"> <!-- Print-only stylesheet --> <link rel="stylesheet" href="print.css" media="print">
<script>
Embeds or links to JavaScript. Usually placed at the end of <body> or with defer/async in <head>.
src
Path to external JS file. If omitted, JS is written inline between the tags.
defer
Downloads script while HTML parses; executes after HTML is fully parsed. Best for most scripts.
async
Downloads script in parallel; executes as soon as it's ready (may interrupt HTML parsing).
type
MIME type. Default is "text/javascript". Use "module" for ES modules.
<!-- External script (best: defer in <head>) --> <script src="main.js" defer></script> <!-- Inline script --> <script> console.log("Hello World"); document.getElementById("btn").addEventListener("click", () => { alert("Clicked!"); }); </script> <!-- ES Module --> <script type="module" src="app.js"></script>
<style>
Embeds CSS directly inside the HTML document. Goes in <head>.
<style> body { font-family: Arial, sans-serif; background-color: #f0f2f5; } h1 { color: #2c3e50; } </style>

4. Headings & Text Content

Headings

<h1> to <h6>
Six levels of headings. <h1> is the most important (main page title — use only one per page). <h6> is the least important. Use headings in order without skipping levels.
<h1>Main Page Title</h1> <h2>Section Title</h2> <h3>Subsection Title</h3> <h4>Sub-subsection</h4> <h5>Minor heading</h5> <h6>Smallest heading</h6>
⚠️ Use headings for document structure, not for visual size. Use CSS to control appearance.

5. Links — <a> Element

<a> — Anchor Element
Creates a hyperlink to other pages, resources, email addresses, phone numbers, or sections of the same page.
href
The URL or destination. Required for a functional link.
target
Where to open: _self (same tab, default), _blank (new tab), _parent (parent frame), _top (full window)
rel
Relationship. Use noopener noreferrer with target="_blank" for security. Also: "nofollow", "alternate", "author"
title
Tooltip text shown on hover
download
Prompts file download instead of navigation. Can specify filename: download="report.pdf"
hreflang
Language of the linked document (e.g., "en", "es")
<!-- External link (opens in new tab safely) --> <a href="https://example.com" target="_blank" rel="noopener noreferrer"> Visit Example.com </a> <!-- Internal link to another page --> <a href="about.html">About Us</a> <!-- Link to a section on the same page (anchor link) --> <a href="#contact">Jump to Contact</a> <section id="contact">Contact section here</section> <!-- Email link --> <a href="mailto:jane@example.com">Send Email</a> <a href="mailto:jane@example.com?subject=Hello&body=Hi there">Email with subject</a> <!-- Phone link --> <a href="tel:+15555555555">(555) 555-5555</a> <!-- Download link --> <a href="files/resume.pdf" download="Jane_Doe_Resume.pdf">Download Resume</a> <!-- Image as a link --> <a href="page.html"> <img src="logo.png" alt="Go to Home Page"> </a>

6. Images & Media

Images

<img> — Image (void element)
Embeds an image into the page. Has no closing tag.
src
Path to the image file (URL or relative path). Required.
alt
Alternative text. Required for accessibility. Describe the image content. Use "" (empty) for decorative images.
width
Width in pixels or percentage (e.g., "300" or "100%"). Helps browser reserve space.
height
Height in pixels. Set both width and height to prevent layout shift.
loading
"lazy" defers loading until near viewport (improves performance). "eager" loads immediately.
srcset
Provides multiple image sources for different screen sizes/resolutions.
sizes
Defines image display size based on viewport width (used with srcset).
title
Tooltip text shown on hover
<!-- Basic image --> <img src="cat.jpg" alt="An orange tabby cat sitting on a windowsill"> <!-- With dimensions (prevents layout shift) --> <img src="photo.jpg" alt="Mountain landscape" width="600" height="400"> <!-- Lazy loading (good for images below the fold) --> <img src="gallery-photo.jpg" alt="Gallery photo" loading="lazy"> <!-- Decorative image (no alt text needed) --> <img src="divider.png" alt=""> <!-- Responsive image with srcset --> <img src="photo-800.jpg" srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w" sizes="(max-width: 600px) 400px, (max-width: 900px) 800px, 1200px" alt="Responsive photo" >
⚠️ Good alt text: Describe what's in the image in context. "Two orange tabby kittens playing with a yarn ball" ✅ | "image" or "photo" ❌
<figure> and <figcaption>
<figure> groups self-contained content (image, diagram, code) with its caption. <figcaption> provides the caption.
<figure> <img src="chart.png" alt="Bar chart showing sales data from 2020–2024"> <figcaption>Figure 1: Annual sales growth from 2020 to 2024.</figcaption> </figure>

Audio

<audio>
Embeds audio content. Use <source> child elements for multiple formats.
src
Path to audio file (alternative to <source> children)
controls
Shows play/pause/volume controls. Boolean attribute — just add the word.
autoplay
Starts playing automatically (often blocked by browsers; use muted with autoplay)
muted
Mutes audio by default
loop
Repeats audio when it ends
preload
"none" (don't preload), "metadata" (load metadata only), "auto" (browser decides)
<audio controls> <source src="audio.mp3" type="audio/mpeg"> <source src="audio.ogg" type="audio/ogg"> Your browser does not support the audio element. </audio>

Video

<video>
Embeds video content.
src
Path to video file
controls
Shows playback controls
width / height
Video dimensions in pixels
poster
Image to show before video plays (thumbnail)
autoplay
Auto-play (combine with muted to work in most browsers)
muted
Starts muted
loop
Repeats video when it ends
preload
"none", "metadata", or "auto"
playsinline
Plays inline on iOS instead of fullscreen
<video controls width="640" height="360" poster="thumbnail.jpg"> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> <track kind="captions" src="captions-en.vtt" srclang="en" label="English" default> <track kind="subtitles" src="subtitles-es.vtt" srclang="es" label="Spanish"> Your browser does not support the video element. </video>
<source> (void element)
Specifies alternative media resources for <audio>, <video>, or <picture>. Browser picks the first supported format.
src
URL of the media file
type
MIME type: "video/mp4", "video/webm", "audio/mpeg", "audio/ogg", "image/webp"
media
Media query (for <picture>)
srcset
List of image candidates (for <picture>)
<track> (void element)
Provides text tracks (captions, subtitles, descriptions) for <video> and <audio>. Uses WebVTT (.vtt) files.
kind
"captions" (for deaf/HoH), "subtitles" (translation), "descriptions" (for blind), "chapters", "metadata"
src
Path to the .vtt file
srclang
Language of the track (e.g., "en", "es")
label
Title shown in the player's track selector
default
Boolean: this track is enabled by default

Iframe — Embedded Web Pages

<iframe>
Embeds another web page (YouTube video, map, etc.) inside the current page.
src
URL of the page to embed
width / height
Dimensions in pixels or percentage
title
Accessible name for screen readers. Required for accessibility.
allowfullscreen
Allows fullscreen mode (needed for YouTube)
loading
"lazy" for deferred loading
sandbox
Applies restrictions: "allow-scripts", "allow-forms", "allow-same-origin"
<!-- YouTube embed --> <iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" title="Video title for accessibility" allowfullscreen loading="lazy"> </iframe> <!-- Google Maps embed --> <iframe src="https://maps.google.com/maps?q=New+York&output=embed" width="600" height="450" title="Map of New York City"> </iframe>
