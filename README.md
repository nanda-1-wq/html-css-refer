# HTML & CSS Reference

A comprehensive HTML reference built while learning through [freeCodeCamp](https://www.freecodecamp.org/). Covers everything from basics to accessibility — designed as a complete reference so you never need to look elsewhere.

## Files

| File | Contents |
|------|----------|
| `HTML/1-html-basics.html` | Document structure, head elements, text, links, images, media, lists, global attributes, entities, void elements |
| `HTML/2-html-semantics.html` | Landmark elements, text-level semantics, quotations, time/date, ruby annotations, figure, interactive elements |
| `HTML/3-html-forms-tables.html` | All input types (22+), form attributes, labels, buttons, textarea, select, datalist, fieldset, tables with colspan/rowspan |
| `HTML/4-html-accessibility.html` | WCAG POUR principles, heading structure, alt text, ARIA attributes, ARIA roles, keyboard navigation, focus management, checklist |
| `HTML/all-html-reference.html` | All of the above combined in one page + HTML definition & history + 25 interview Q&A |
| `CSS/style.css` | Shared styles |

## How to Use

Open any file directly in your browser — no server needed. The sticky navigation bar at the top links between all five files.

Start with `HTML/all-html-reference.html` for a full overview, or jump to a specific file for focused revision.

## Topics Covered

- HTML5 document structure and boilerplate
- Semantic HTML and landmark elements
- Every HTML input type and form attribute
- Complete table reference with merging (colspan/rowspan)
- WCAG 2.1 accessibility guidelines (POUR)
- Full ARIA attributes and roles reference
- Keyboard navigation and focus management
- HTML entities, void elements, global attributes
- Meta tags, Open Graph, viewport
- Responsive images (`srcset`/`sizes`)
- Audio/video with captions (`<track>` + WebVTT)
- Browser rendering pipeline
- 25 HTML interview questions and answers
